# 매뉴얼 01. 집 PC 학습 환경 설정 (RTX 5060 Ti 16 GB)

한 번만 하면 된다. 예상 1~2 시간(내려받기 포함). 끝나면 `python -m helpai_decide check-env` 가 **통과**를 출력해야 한다.

> 전제: Windows 11 + NVIDIA RTX 5060 Ti 16 GB. 학습은 **WSL2 Ubuntu** 안에서 한다(학습·ONNX 도구가 리눅스에서 가장 매끄럽다).
> 디스크 여유 **20 GB 이상**(기반 모델 0.8 GB, 학습 결과, ONNX fp32 1.7 GB, INT8, 캐시).

---

## 1. NVIDIA 드라이버 (Windows 쪽)

1. NVIDIA 공식 사이트에서 RTX 50 계열을 지원하는 **최신 Game Ready / Studio 드라이버**를 Windows 에 설치한다.
   WSL 안에는 드라이버를 따로 깔지 않는다(Windows 드라이버가 WSL 에 GPU 를 넘겨준다).
2. PowerShell 에서 확인:

```powershell
nvidia-smi
```
`NVIDIA GeForce RTX 5060 Ti`, `16311MiB` 비슷한 줄과 `CUDA Version: 12.8` 이상이 보이면 된다.

## 2. WSL2 Ubuntu

관리자 PowerShell:

```powershell
wsl --install -d Ubuntu-24.04
```
재부팅 후 Ubuntu 창에서 사용자 이름·암호를 만든다. 이후 명령은 **모두 Ubuntu 창(bash)** 에서.

```bash
nvidia-smi                       # WSL 안에서도 GPU 가 보여야 한다
sudo apt update && sudo apt install -y git python3-venv python3-pip build-essential curl
python3 --version                # 3.12.x (3.10 이상이면 된다)
```
> ⚠ 작업 폴더는 **리눅스 쪽(~/)** 에 둔다. `/mnt/c/...` 에서 돌리면 파일 읽기가 몇 배 느리다.

## 3. Node.js 20+ (집 PC 에서 젯슨과 같은 추론 서버로 평가하기 위해)

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
node --version                   # v20 이상
```

## 4. 저장소 받기

```bash
mkdir -p ~/work && cd ~/work
git clone -b decision_model https://github.com/Lumiela/helpai.git helpai-decision
cd helpai-decision
```

## 5. 파이썬 가상환경 + PyTorch(cu128) + 학습 패키지

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -U pip wheel
# ★ RTX 50 계열(Blackwell, sm_120)은 CUDA 12.8 용 휠이 필요하다. 반드시 이 줄을 먼저:
pip install torch --index-url https://download.pytorch.org/whl/cu128
python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_capability(0), torch.cuda.get_arch_list())"
```
`True (12, 0)` 와 목록에 `sm_120` 이 보여야 한다. 그다음:

```bash
pip install -r requirements-train.txt
```

> ⚠ `laya` 가 다른 torch 판을 요구하면 pip 가 torch 를 PyPI 판으로 바꿔 깔 수 있다. 아래 6 단계 check-env 에서
> `sm_120 를 지원하지 않는다` 가 나오면 cu128 판으로 다시:
> `pip install --force-reinstall torch --index-url https://download.pytorch.org/whl/cu128`
>
> `laya[fast]`(TileLang)·FlashAttention 은 **깔지 않는다** — RTX 50 계열 지원이 확인되지 않았다. 기본 어텐션으로 충분하다.

## 6. 환경 점검

```bash
python -m helpai_decide check-env
```
보는 것:
- `GPU  NVIDIA GeForce RTX 5060 Ti  sm_120  15.9 GB` · `✓ GPU 연산 시험 통과`
- `laya 0.5.5` · `TrainConfig 필드: epochs, micro_batch, …` · `laya.train.finetune (data, model_dir, output_dir, config=None, device='auto')` 비슷한 줄
- 마지막 줄 `결과: 통과`

**`laya.train.finetune ... 없음`** 이 나오면 laya 판이 바뀐 것이다 → 출력 전체를 저장해 두고 매뉴얼 04 의 "학습 API 이름이 다르다".

## 7. ONNX 내보내기 도구 (receptron/laya)

```bash
mkdir -p ~/src && git clone https://github.com/receptron/laya ~/src/laya-onnx
git -C ~/src/laya-onnx rev-parse --short HEAD        # 이 커밋이 묶음 manifest 의 exporter_commit 으로 기록된다
ls ~/src/laya-onnx/export/export_onnx.py
```
내보내기 스크립트는 우리 `.venv` 의 파이썬으로 돌린다(torch·onnx·onnxscript 는 5 단계에서 이미 깔림).

## 8. 추론 서버 의존성 (edge)

```bash
cd ~/work/helpai-decision/edge
npm install                    # @receptron/laya 0.2.0 + onnxruntime-node (리눅스 x64)
cd ..
```
`package-lock.json` 이 생기면 커밋해 둔다(젯슨 빌드가 같은 판을 쓰게).
