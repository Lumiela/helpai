# CUBE001 센서 데이터 분석 — 설비 기준 반응 · 센서 간 상관

> 작성: 랩탑 ClaudeCode (Claude Opus 5.5). 분석: 2026-11-27.
> 팀 내부 작업일지(센서·설비 작업일지 60~63절)를 외부 공유용으로 정리한 문서다. 수치는 작업일지와 같다.
> 코드·데이터·결과는 [`../corr-test/`](../corr-test/) 에 있다.

## 1. 전제

- **분석 관점**: 큐브는 반밀폐 상태라 기온은 설비를 따라가는 값으로 본다. 그래서 설비(LED·배기팬·순환팬·펌프)를 원인, 센서를 반응으로 놓고 분석했다(3절). 센서끼리의 상관(4·5절)은 참고용이다.
- **센서 위치**
  - RS485 토양 7종 센서는 **공기 중**에 있다. 이 기간 `soil_temp` 는 공기 온도이고, EC·질소·인·칼륨·염분·수분 0, pH 7.0 고정은 공기 중이라서 나온 값이다.
  - 토양수분센서(SEN0193)는 **화분 흙 속**에 있다.
- **데이터**: 네이버 클라우드 서버 InfluxDB 의 CUBE001 기록을 1분 평균으로 읽었다(읽기만 함).
- **전류**: `power_a` 는 2026-11-26 11:06 ~ 11:09 사이 크기가 약 1/5 로 바뀌었다(11-25 하루 중앙값 23.785 A → 11-26·27 4.797 A). 션트 저항을 R002 가정에서 R010 으로 고친 펌웨어와 맞는 변화다. 분석에는 11:09 이후 값만 썼다.

## 3. 설비 기준 분석

### 3.1 방법

| 계산 | 내용 |
|---|---|
| 사건 | 설비 값(반올림)이 바뀌고, 바뀌기 전 10분·바뀐 뒤 10분 동안 값이 그대로인 시점 |
| 격리 | 사건 앞 10분 ~ 뒤 60분에 다른 설비 변경(같은 분 포함)이 없고, 앞뒤 5분에 장치 재시작이 없음. 펌프·모터는 1분 평균이 0 보다 크면 움직인 것으로 봄 |
| 반응 | (사건 뒤 h분 전후 5분 평균) − (사건 직전 5분 평균), h = 5·15·30·60 |
| 대조 | 앞뒤 60분에 설비 변화·재시작이 없는 시각 2,518개(30분 간격) 중 사건과 같은 시간대(±1시간)에서 같은 계산 |
| 대조 비율 | 대조 시각 중 \|변화\| 가 사건 중앙값의 \|변화\| 이상이었던 비율(작을수록 저절로는 드문 변화) |
